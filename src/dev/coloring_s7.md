# 第七季塗色本 4 張（給美術）

2026-11-22　星光工作室 Starlight Studio　著作權與 IP 屬於星光工作室

格式照第六季 `S36.PICS`：
- 畫布 200×200。
- `r`：可以塗的區塊，用封閉路徑。`deco`：畫在線上面、不能塗的裝飾線，例如臉、紋路。
- 線條 `#3A2A5C`，寬 2.5。分類 `cat:'adv'`（大冒險）。完成那一章才打開。
- 區塊不要太碎，4～7 歲用手指塗得到。最小的區塊大約 12×12 以上。
- 不寫字、不畫任何真實的標誌或品牌，沒有價格。

## 1. 捷運列車（第 41 章打開，`lv:2`）
- 構圖：一列兩節的捷運列車停在高架軌道上，從側面看，車頭在右邊，圓圓的、帶笑臉的車頭燈。後面是三四棟高低不一的城市大樓，天上一朵雲、一個太陽。
- 可塗區塊（約 16 塊）：
  - 車身上半、下半
  - 車頭
  - 兩扇車門，每節各一
  - 四個車窗（窗裡可以看到兩個小乘客的頭，只畫輪廓，可以塗）
  - 軌道、橋墩
  - 三四棟大樓（每棟一塊，加一兩排窗）
  - 太陽、雲
- 裝飾（不能塗）：
  - 車身上一條腰帶線
  - 車門中間的縫
  - 車頭燈的笑臉
  - 輪子的軸
- 不要畫：路線顏色帶、站名、任何真實捷運的配色或標誌。

## 2. 書架（第 42 章打開，`lv:1`）
- 構圖：一座三層的木頭書架，正面看。
  - 上層：五六本直立的書，高矮不同，一本斜靠著。
  - 中層：兩本平放疊起來的書，旁邊一盆小盆栽。
  - 下層：一個裝繪本的籃子，露出三本繪本的書背。
  - 書架頂上坐著貓頭鷹館員書書（簡化線稿，眼鏡和背心分開成區塊）。
- 可塗區塊（約 18 塊）：
  - 書架側板、層板
  - 每本書的書背
  - 盆栽的盆和葉子
  - 籃子
  - 書書的身體、背心、肚子
- 裝飾（不能塗）：
  - 書背上的小圖案（星星、愛心、小魚，不寫字）
  - 木紋短線
  - 書書的眼睛和眼鏡框

## 3. 動物園的動物（第 44 章打開，`lv:2`）
- 構圖：動物園草地上，三個朋友站在一起。
  - 左邊：長頸鹿，只畫到肩膀以上，從畫面左邊伸進來。
  - 中間：大象，噴出一道小水柱。
  - 右前方：小貓熊環環抱著自己的尾巴。
  - 背景：一棵竹子、一座小木牌。木牌只畫成一片葉子的形狀，不寫字。
- 可塗區塊（約 20 塊）：
  - 長頸鹿：身體，斑點 4～5 塊（各自封閉）
  - 大象：身體、耳朵、水柱
  - 小貓熊：身體、臉的白色部分、耳朵；尾巴分成一圈一圈，6 圈，每圈一塊，讓孩子可以交錯塗
  - 竹子、草地、天空
- 裝飾（不能塗）：
  - 眼睛
  - 小貓熊臉上的淚痕線
  - 大象的鼻子紋
- 小貓熊不要畫成大貓熊（黑白熊貓）。

## 4. 畫框（第 45 章打開，`lv:1`）
- 構圖：美術館牆上掛著一個大大的、有花邊的畫框。
  - 畫框裡是一幅簡單的畫：一顆大太陽、一座小房子、一棵樹、兩朵花。這幅畫代表「你的畫」。
  - 畫框下面有一張空白的小牌子，只畫長方形，不寫字。
  - 牆邊站著變色龍小畫家變變，拿著調色盤。
- 可塗區塊（約 17 塊）：
  - 畫框外框、內框
  - 花邊四個角的花（各一塊）
  - 畫裡的太陽、房子牆、屋頂、門、樹冠、樹幹、兩朵花、草地
  - 變變的身體、貝雷帽、調色盤
- 裝飾（不能塗）：
  - 調色盤上的顏料點
  - 變變的眼睛
  - 畫框的雕花短線
- 房間佈置「我的畫」（第 45 章獎品）可以借這張的畫框外形，框裡放孩子自己塗好的塗色本作品。
