# 第七季內容：查證來源和寫法說明

2026-11-22　星光工作室 Starlight Studio

## 安全內容的依據（台灣現行宣導）

**捷運**
- 手扶梯「緊握扶手、站穩踏階」，不在手扶梯上走動、奔跑。
  - 來源：北捷宣導，工商時報 2025-06-08 <https://www.ctee.com.tw/news/20250608700368-431401>
- 不穿長裙、膠鞋搭手扶梯；站在黃色框框裡；扶手兩側的縫和疏齒板是危險區；到出口要往前跨一步；孩子要站穩、不活蹦亂跳。
  - 來源：TVBS <https://news.tvbs.com.tw/life/1158228>
  - 遊戲裡寫成「長裙和鞋帶離邊邊遠一點」「到了出口跨一步走開」。
- 頭和手不伸出扶手外：一般手扶梯安全標示的內容。
- 車門：進車廂後往內移動、跟車門保持距離，減少異物卡門。
  - 來源：中央社 2019-07-17 <https://www.cna.com.tw/news/ahel/201907170212.aspx>
  - 遊戲裡寫成「不擋門、不靠門、手不放門縫」。
- 「警示音響了不衝」：照大綱的粗體，也是捷運站廣播的固定內容。
  - 已經有「捷運門要關了，嗶嗶嗶在響，要怎麼做？」這一題，所以這次改成兩題新情境：嗶嗶聲代表什麼、可不可以用手或背包擋門。
- 月台空隙：「注意月台間隙」是車站固定廣播內容。東西掉下去要找站務人員，不自己撿、不跳下去。
- 坐過站、在捷運站走散：照大綱的粗體寫成「留在月台，找穿制服的站務員」。
  - 這是常見的親子安全做法，我沒有找到北捷官方原文。
  - 遊戲裡不教「下一站下車再坐回來」這種比較複雜的做法，只教留在月台找站務員。
- 車廂對講機：列車上有緊急對講機。題目只教孩子「告訴身邊的大人」，由大人去用。

**用藥**
- 藥品放在孩童拿不到的地方；教孩子「藥品不是零食，絕對不可以隨意食用」；外觀像糖果的藥特別容易誤會。
  - 來源：食藥署《藥物食品安全週報》第 952 期 <https://www.fda.gov.tw/TC/PublishOtherEpaperContent.aspx?id=1487&tid=4568>
- 不把成人藥給孩子用、不自行停藥、不用以前剩下的藥。
  - 來源：衛福部 <https://mohw.gov.tw/cp-16-80096-1.html>
  - 遊戲裡寫成：別人的藥不能吃、藥苦苦的不偷偷吐掉而是告訴大人、藥交給大人收好。
- 已經有「藥可以自己拿來吃嗎？」這一題，這次換成新情境：像糖果的彩色藥、哥哥的感冒藥、藥由誰拿給你、拿到藥交給誰。
- 發燒照大綱只寫「身體發燙告訴大人」，不出溫度計、不出度數。

**走失**
- 孩子說出父母電話，由工作人員幫忙聯絡、陪伴孩子。
  - 案例：移民署 <https://www.immigration.gov.tw/5385/7229/7238/420078/cp_news>
- 「站在原地、找穿制服的工作人員或服務台、記住名字和電話、出門前約好」：照大綱的粗體。
  - 已經有「站在原地找警察／店員」的題，這次換成動物園的工作人員、服務台、約定地點。
  - 不提陌生人，留給第 47 章。
- 電話：只教「記住爸媽電話，請工作人員幫你打」，遊戲裡不輸入電話。

**美術館**
- 大部分展覽可以拍照但有例外；拍照不用閃光燈，因為強光會損傷作品；不越線、不觸摸作品；不嬉鬧、不奔跑、不在展區飲食。
  - 來源：台北市長安國小《參觀美術館之前》 <https://www.cjps.tp.edu.tw/campus/sites/www.cjps.tp.edu.tw/files/page/2022/12/10622/%E5%8F%83%E8%A7%80%E7%BE%8E%E8%A1%93%E9%A4%A8%E4%B9%8B%E5%89%8D.pdf>
- 大包包放寄物櫃：一般美術館的入館規定，各館不同，題目只說「可以先放」。

**動物知識**
- 小貓熊：主要吃竹葉，也吃果子；很會爬樹，常在樹上休息。
- 大象：用鼻子吸水再噴進嘴裡；用泥巴和沙子保護皮膚。
- 長頸鹿：吃高處的樹葉。
- 變色龍：會隨心情、溫度變色。題目寫「跟著心情和天氣變」，沒說「為了躲起來」，因為那個說法不完全對。

## 用詞

- 捷運、動物園、美術館、圖書館都不寫真名，也不出現卡片的名字。
  - 「借書證」是一般名詞，留著。
  - 故事裡原本想寫「健保卡」，後來刪掉了。
- 「手扶梯」照大綱的寫法。遊戲裡第 17 章有一句「電扶梯」，兩個詞台灣都在用。
- 小貓熊叫「環環」，不用任何真實動物明星的名字。
- 數字要念的地方都寫國字，例如「第四廳」「兩格」。
  - 百數表、叫號、時鐘這些用數字的地方，照現有做法用 `n|` 錄音，前後接 `p|` 片段。
